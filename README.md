# Fleet Carrier Trade Command website

Static GitHub Pages site for the Fleet Carrier Trade Command Elite Dangerous companion application.

## Publish with GitHub Pages
1. Create a public GitHub repository named `FleetCarrierTradeCommand` (or another name you prefer).
2. Upload `index.html`, `privacy.html`, and `style.css` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. GitHub will display the published Pages URL after deployment.
6. Use that published HTTPS URL as the Frontier Developer Zone **Application Homepage URL**.

Do not put OAuth client secrets, access tokens, refresh tokens, passwords, or other credentials in this repository.
