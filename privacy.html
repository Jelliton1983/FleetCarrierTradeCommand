FLEET CARRIER TRADE COMMAND

Privacy Policy

How the application handles Frontier authorization and local data.

Overview

Fleet Carrier Trade Command is an Elite Dangerous companion utility. Its Frontier-connected features use user-authorized access to Frontier's Companion API (CAPI).

Frontier Login

The application is designed to use Frontier's official OAuth authorization process. Users authenticate on Frontier's website. Fleet Carrier Trade Command does not request, receive, or store a user's Frontier account password.

OAuth Tokens

After authorization, OAuth access and refresh tokens may be stored locally on the user's device so authorized CAPI features can operate and renew access. Tokens are used only to communicate with Frontier services on behalf of the authorized user. Users can log out of the application and can revoke authorization through Frontier's account controls.

Data Used by the Application

Depending on enabled features, the application may process Elite Dangerous market information, Commander/account information returned by authorized Frontier APIs, Fleet Carrier status, carrier commodity orders, carrier location, and locally generated application settings or activity history.

Local Storage

The desktop application stores settings and market/cache information locally on the user's computer. Mobile builds may use operating-system secure storage for authorization tokens. The project website itself does not require users to submit Elite Dangerous credentials.

Third-Party Services

The application may communicate with Frontier services for authorized account/carrier data and public Elite Dangerous data services such as EDDN or public galaxy-data sources for market information. Those services operate under their own terms and privacy practices.

Independent Project

Fleet Carrier Trade Command is an independent community project and is not affiliated with, endorsed by, or sponsored by Frontier Developments plc.

Changes

This policy may be updated as Fleet Carrier Trade Command gains new features. The current version will be published on this project site.
